# Brutalismo neón

- Fondo: `#0a0a0a`. Texto: `#39ff14`.
- Tipografía: `"Courier New", monospace`, `text-transform: uppercase`.
- Bordes: `6px solid #ff00ff`, sin `border-radius`.
- Sombras duras: `box-shadow: 10px 10px 0 #ff00ff`.
